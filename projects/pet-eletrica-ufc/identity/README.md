O worktree contém um logotipo raster fornecido como `identity/logos/pet_logo.png`; uma cópia de trabalho está em [`../assets/logos/pet_logo.png`](../assets/logos/pet_logo.png). O arquivo é PNG transparente, 272 × 182 px. A cor dominante observada na marca é azul índigo próximo de `#150077`; considerar esse valor uma amostra do arquivo, não uma paleta oficial especificada. Não há SVG nem manual de marca fornecido.

Para serigrafia PCB, preservar proporções e usar versão vetorial monocromática derivada somente após aprovação visual. A representação em serigrafia não reproduz cor; reservar o azul para identidade documental/visual da placa. Não modificar nem substituir o PNG de origem.
